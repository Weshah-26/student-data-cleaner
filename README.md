# Student Data Cleaner
A beginner-friendly Python project for cleaning and processing student data using lists, loops, functions, map(), and filtering techniques.
# What I practiced

- Lists
- For loops
- Functions
- `isinstance()`
- `map()`
- `filter()`
- Lambda functions
- Conditional statements

# Project Goal

This project takes a list containing student names and unwanted numeric values, cleans the data, transforms the names, and filters students based on their name length.

# What I Learned

Through this project, I practiced how to:

- Create and use functions
- Store a function's result in a variable
- Use `continue` inside loops
- Build a new list from cleaned data
- Use `map()` and `filter()` with lambda functions
